# 📒 My Account Book PWA

简洁高效的个人记账应用，作为 PWA（渐进式 Web 应用）部署，可安装到手机主屏幕，离线可用，零费用零备案。

## ✨ 功能特性

| 功能 | 说明 |
|------|------|
| 快速记账 | 支出/收入一键切换，金额支持逗号分隔（如 `1,234.56`） |
| 智能拆分 | 备注+金额一句输入，如`买水果15`自动拆分 |
| 余额总览 | 顶部深色卡片实时显示当前余额，负数红色提示 |
| 固定收入 | 设置每月固定收入后自动添加，省心省力 |
| 编辑记录 | 点击任意流水可修改备注和金额 |
| 筛选搜索 | 日期范围筛选 + 金额/备注关键词搜索 |
| 支出统计 | 周/月/年维度柱状图可视化对比 |
| 数据安全 | 所有数据存于本地 `localStorage`，不上传服务器 |

## 🗂️ 项目结构

```
My account book PWA/
├── index.html      # 应用主页面（单文件应用，含全部样式与逻辑）
├── manifest.json   # PWA 配置（名称、图标、主题色、显示模式）
├── sw.js           # Service Worker（离线缓存）
├── icon-192.png    # 应用图标 192x192
└── icon-512.png    # 应用图标 512x512
```

## 🚀 快速开始

### 本地预览

```bash
# 方式一：使用 npx 静态服务器
npx serve .

# 方式二：Python
python -m http.server 8080
```

浏览器打开 `http://localhost:8080` 即可使用。

### 部署到公网（已完成）

1. 将项目推送到 GitHub 仓库
2. 在 [Vercel](https://vercel.com) 中导入该仓库
3. 部署完成后获得 HTTPS 链接（ `https://my-account-book-opal.vercel.app`）

### 安装到手机

1. 手机（Android + Chrome）打开部署后的链接
2. 浏览片刻后，底部弹出「添加到主屏幕」（或点击菜单 → 安装应用）
3. 主屏幕出现「记账本」图标，点击即全屏运行，无需打开浏览器

> 安装后支持离线使用，断网也能正常记账。

## 🛠️ 技术栈

- 原生 HTML / CSS / JavaScript（零依赖）
- Canvas 2D 绘制统计图表
- localStorage 数据持久化
- Service Worker 离线缓存
- Web App Manifest 应用安装

## 📊 数据说明

- 数据键名：`my_account_data`（账目）、`my_account_settings`（设置）
- 存储位置：浏览器本地 `localStorage`，清除浏览器数据会丢失账目，请定期备份
- 卸载 PWA 或清除站点数据前建议导出记录
